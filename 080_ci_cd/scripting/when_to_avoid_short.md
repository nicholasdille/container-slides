## When to Avoid Shell Code

### Length

[Predecessor of uniget](https://github.com/nicholasdille/docker-setup/blob/v1.7.47) was 900 lines of code in bash

### Complexity

[Predecessor of uniget](https://github.com/nicholasdille/docker-setup/blob/v1.7.47) was sourcing 4 files with 1000 lines of code

### Readability

Oneliners, language constructs, shell dialect, sourcing files, structured data

### Maintainability

Many required tools, structured data

### Performance

External tools, excessive forking

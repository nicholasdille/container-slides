## When to avoid shell code

### Length and Complexity

[Predecessor](https://github.com/nicholasdille/docker-setup/blob/v1.7.47) of `uniget`:
- 900 lines of code in bash
- Sourced 4 files with 1000 lines of code

Now 12.000 LoC of Go code <i class="fa fa-face-smile-wink"></i>

### Readability

Oneliners, language constructs, shell dialect, sourcing files, structured data

### Maintainability

Many required tools, structured data

### Performance

External tools, excessive forking

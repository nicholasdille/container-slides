## Alternatives

### Programming language

Choices include: Go, Rust, Java, C#, Python, Ruby, Perl, PowerShell

The runtime becomes a hard dependency

### Wrap in `Dockerfile`

Manages the runtime environment and creates a shippable unit

Intermediate step before switching to another language

### Abstraction

Consume logic from existing tools (Ansible, OpenTofu, Docker Compose)

### Simplify

Complexity caused by design decisions (replace `xmlstarlet` with `gomplate`)

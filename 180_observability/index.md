# Workshop: Observability for Cloud Native

This site contains the exercises to learn about observability.

## Audience

Software developers and system administrators who want to learn observability.

## Duration

One day

## Expected knowledge

Understanding of Kubernetes and container orchestration

## Goals

Understand observability and its meaning in the context of cloud native infrastructure

## Style

40% theoretical introduction

60% practical exercises

The instructor will provide an introduction to each topic. Participants will then work on exercises. The instructor will be available to answer questions and provide hints. The instructor will also be able to demonstrate solutions to the exercises.
